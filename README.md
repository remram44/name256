This page encodes bytes into pronounceable 3-letter words (base 256).

This scheme was invented by wbic16 and is described [on their blog](https://hewo.xedoloh.com/2015/04/base-256/) ([archive.org link](https://web.archive.org/web/20150425043440/https://hewo.xedoloh.com/2015/04/base-256/)).

Examples:

- 0xE4 (228) -> yec
- 0x08E5FBD6 -> bic yed zim wef
